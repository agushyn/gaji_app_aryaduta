## 2. Temuan Audit (Numbered Findings List)

Berdasarkan audit antislop pasca-implementasi Phase 5, berikut catatan bernomor dengan prioritas:

### Temuan #1 [LOW: Quality Lock: R-27 Keamanan dan Integritas Dokumen PDF Privat]
- **File:** `app/Services/PayslipPdfService.php` & `app/Http/Controllers/PayslipController.php`
- **Aturan:** R-27 (Integritas Data dan Keamanan Penyimpanan Berkas Finansial)
- **Keterangan:** Berkas PDF disimpan di direktori privat `storage/app/private/payslips/{period_id}/` dengan nama berkas acak berstempel identitas slip dan SHA-256. Pengunduhan dan pratinjau hanya dilayani via response streaming bertanda tangan otorisasi Laravel, disertai pencatatan audit log `payslip.pdf_previewed` dan `payslip.pdf_downloaded`.

### Temuan #2 [LOW: Quality Lock: R-32 Layout PDF Responsif dan Aman dari Pemotongan Halaman]
- **File:** `resources/views/pdf/payslip.blade.php`
- **Aturan:** R-32 (Kompatibilitas Rendering PDF Engine Standar)
- **Keterangan:** Template PDF dirancang menggunakan tabel HTML murni dan CSS inline yang sepenuhnya kompatibel dengan DomPDF (`border: 1px dashed #222`, font `DejaVu Sans`), menghindari ketergantungan Tailwind CDN runtime atau flexbox/grid CSS yang tidak didukung cpdf. Telah diuji dengan data uji hingga 20 komponen rincian gaji tanpa memotong tabel atau tanda tangan.

## 3. Verifikasi Acceptance Gate Phase 5

- [x] **PDF Sesuai Layout Template Referensi:** Tampilan PDF mencakup identitas perusahaan CV. Bina Pustaka, judul SLIP GAJI KARYAWAN, kotak informasi dua kolom, tabel rincian GAJI dan POTONGAN GAJI dengan pemisah garis putus-putus, GAJI BRUTO, TOTAL POTONGAN, UANG DINAS, TOTAL TERIMA GAJI, dan tiga kolom penandatangan (Personalia, Yang Menyerahkan, Yang Menerima).
- [x] **Semua Data Berasal dari Snapshot Sah:** Data identitas (nama, NIK, jabatan, cabang/divisi, kontak), periode, hari kerja, komponen gaji, nominal, kuantitas/tarif, dan penandatangan disimpan permanen dalam kolom snapshot `payslips` dan `payslip_items`. Mutasi pada master karyawan atau master komponen tidak mengubah slip historis.
- [x] **Finalisasi Tanpa Approval Ditolak:** Finalisasi slip maupun periode hanya diizinkan jika status telah `approved` dan aktor memiliki permission `payslips.finalize`.
- [x] **PDF Privat Tanpa URL Publik Permanen:** Berkas PDF tersimpan di disk lokal privat di luar `public/` dan disajikan secara terkontrol melalui endpoint terautentikasi dan terotorisasi.
- [x] **Hash Tersimpan dan Valid:** Checksum SHA-256 (64 karakter heksadesimal) dihitung saat generasi berkas dan diverifikasi valid terhadap isi fisik berkas PDF.
- [x] **Idempotensi Finalisasi:** Percobaan ulang (retry) finalisasi tidak menghasilkan nomor slip baru atau berkas duplikat yang berulang.
- [x] **Mekanisme Pembatalan (Void) Tercatat:** Slip final yang dibatalkan memerlukan alasan pembatalan tertulis (wajib), mencatat identitas aktor pembatal dan stempel waktu, serta mencatat entri pada `payroll_approval_events` dan `audit_logs`.
- [x] **Unit & Feature Test Lulus 100%:** Seluruh 99 pengujian fitur dan unit test pada sistem lulus tanpa kegagalan (415 assertions).
